about=ArchaeoGlyph helps archaeologists create factual, standardized symbols for GIS maps. Drop in an artifact photo or a measured drawing and generate map-ready SVG symbols using Auto Trace, AI (Google Gemini, Hugging Face, or local Stable Diffusion), or built-in templates. Symbols are recolourable in QGIS, and features include style controls (Simple Symbol/Line/Measured), optional background-removal models, target layer selection, graduated sizing, and direct symbol library integration.

about[ko]=ArchaeoGlyph는 고고학 조사 결과를 GIS 지도에 표현할 때 쓰는 표준 심볼을 만들어 줍니다. 유물 사진이나 실측도·탁본을 넣으면 자동 추적, AI(Google Gemini, Hugging Face, 로컬 Stable Diffusion), 또는 내장 템플릿으로 지도용 SVG 심볼을 생성합니다. 생성된 심볼은 QGIS에서 색을 바꿀 수 있고, 표현 방식(단순 심볼·선묘·실측도) 선택, 배경 제거 모델, 대상 레이어 지정, 단계별 크기 조정, 심볼 라이브러리 연동을 지원합니다. UI는 QGIS 언어 설정에 따라 한국어로 표시됩니다.

changelog=
    0.2.0 - Vector output, factual Auto Trace, working AI backends
        * Symbols are produced as SVG markers with param(fill)/param(outline)
          and stored in the QGIS profile, so they stay sharp and recolourable
        * Auto Trace split into testable modules; fixed silently broken polar
          motif extraction, discarded alpha channels, ignored EXIF rotation,
          non-deterministic colours and a no-op line filter
        * Schematic structure lines are opt-in; only observed lines are drawn
        * Ink Centerline v2: colour-aware, halo-suppressed, junction-aware,
          with automatic photograph/drawing routing
        * Optional ONNX background removal with verified model downloads
        * Gemini: stroke styles work again, SVG is parsed and sanitised,
          model fan-out capped, fallbacks are visible
        * Hugging Face: calls go through the inference providers with the
          right pipeline per model
        * API keys move to the QGIS authentication database
        * Generation can be cancelled; CI runs lint, tests and packaging
    0.1.1 - Branding/metadata/docs refresh
        * Display naming unified to ArchaeoGlyph
        * Author metadata updated
        * README rewritten for current feature set
        * Added citation, star request, and Ko-fi support section
    0.1.0 - Stable baseline
        * English-first UI and naming
        * Styles: Colored, Typology, Line, Measured
        * Reference-first HF generation (modern model fallback)
        * Gemini factual-mode safeguards with deterministic fallback
        * Optional SAM backend with beginner quick setup controls
        * Expanded built-in template catalog
        * Added typology-inspired template variants (bronze dagger classes, keyhole tomb variants)
        * Added projectile-point typology templates and expanded template browser filters
        * Color adjustment and proportional sizing
        * Target layer selector for Apply to Layer
        * Graduated sizing controls: explicit field picker + class count
        * Default symbol size tuned to 10 mm
        * Expression sliders: factuality, symbolic looseness, exaggeration
        * Shared style-control utilities to reduce hardcoded duplicates
        * QGIS symbol library integration
